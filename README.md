# C Projects Collection

A collection of beginner-to-intermediate C programming projects combined into a single menu-driven application.

## About

This project was created while learning the C programming language and fundamental programming concepts. It combines several small projects into one terminal application, allowing the user to choose different programs from a main menu.

The goal of this project was to practice:

* Functions
* Loops
* Conditional statements
* Input validation
* Arrays and matrices
* Modular thinking
* Problem solving
* Program organization

## Features

### 1. Multiplication Table

Generates a multiplication table for a user-provided number.

### 2. Circle Area Calculator

Calculates:

* Circle area
* Circle perimeter

based on the given radius.

### 3. Cash Register

Simulates a simple payment system with:

* Loyalty card discounts
* Extra discounts
* PIN verification
* Balance checking

### 4. Sum of Numbers

Accepts multiple numbers from the user and calculates their total sum.

### 5. Electricity Price Calculator

Calculates:

* Electricity cost per kWh
* VAT amount
* Monthly electricity consumption
* Savings when switching from incandescent bulbs to LED bulbs

### 6. Mario Tower

Builds a Mario-style tower using ASCII characters and displays row statistics.

### 7. Sequence Generator

Generates:

#### Arithmetic Sequences

Example:
1, 3, 5, 7, 9 ...

#### Geometric Sequences

Example:
2, 4, 8, 16, 32 ...

### 8. Extreme Values in Matrix

Creates a user-defined matrix and calculates:

* Average value
* Maximum value
* Minimum value

## Skills Practiced

During this project I learned and practiced:

* Function declarations and definitions
* Passing arguments to functions
* Returning values from functions
* Input validation with `scanf`
* Buffer cleaning using `getchar`
* Nested loops
* Variable Length Arrays (VLA)
* Working with 2D arrays
* Basic software structure
* Creating reusable helper functions

## Compilation

Using GCC:

```bash
gcc main.c -o CProjects
```

Run:

```bash
./CProjects
```
